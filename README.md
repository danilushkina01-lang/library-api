# Library API

API для сервиса «Библиотека»: управление книгами, читателями и выдачами.

## Основные возможности

- CRUD для книг (`/books`) и читателей (`/readers`).
- Управление выдачами (`/loans`): создание, список, возврат.
- Фильтры, сортировка и пагинация для всех списков.
- Единая модель ошибок и бизнес-правила.
- Идемпотентность для операций создания.

## Документация

- `openapi.yaml` — контракт API в формате OpenAPI 3.1.
- `STYLE.md` — правила оформления API.
- `REVIEW.md` — чек-лист самопроверки.

## Как использовать

1. Открой `openapi.yaml` в редакторе (Swagger UI, Redoc, VS Code).
2. Изучи пути, параметры и примеры.
3. Реализуй серверную часть согласно контракту.
